# Desmond Nador — Junior Frontend Developer Portfolio

A responsive portfolio built with plain HTML, CSS and JavaScript.

## Files
- `index.html` — portfolio content and structure
- `style.css` — dark/glowing responsive design
- `script.js` — mobile menu, reveal animations and footer year

## Run locally
Open `index.html` in a browser. Keep all three files in the same folder.

## Deploy
This static site can be hosted with GitHub Pages, Netlify, Vercel, or Railway.
